## 🤝 협업 워크플로우 (공통 요약)

트랙과 무관하게 팀 공용 레포지지토리를 다루는 기본 흐름은 동일합니다.

1. 본인 팀의 공용 레포지토리 초대를 수락하고 clone합니다.
    ```bash
    git clone <팀 공용 레포지토리 URL>
    ```
2. `main`에 직접 커밋하지 않고 `feature/` 브랜치를 만들어 작업합니다.
    ```bash
    git checkout -b feature/<본인이름-작업내용>
    ```
3. 작업 후 add / commit 하고, 본인 브랜치를 push합니다.
    ```bash
    git add .
    git commit -m "커밋 메시지"
    git push origin feature/<본인이름-작업내용>
    ```
4. GitHub에서 **Compare & pull request**로 PR을 생성하고, 팀원을 Reviewer로 지정합니다.
5. 리뷰 코멘트를 반영해 같은 브랜치에 추가 커밋 후 다시 push합니다.
6. 리뷰 승인(Approve) 후 **Merge pull request**로 병합합니다.
